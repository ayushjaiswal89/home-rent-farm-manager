
  # Complete Business Management App

  This is a code bundle for Complete Business Management App. The original project is available at https://www.figma.com/design/7qtRtweJJzpZfcdbYUjxUG/Complete-Business-Management-App.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  The app works with local storage when `firebase-applet-config.json` is empty. To enable cloud sync and Google Sheets, add your Firebase web app configuration to that file, enable the Google sign-in provider, authorize your app's domain in Firebase Authentication, and enable the Google Sheets API in the linked Google Cloud project.
